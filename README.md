# INF 552 Homework 2

## Structure

- `notebook/Patel_Khushi_HW2.ipynb` contains the homework solutions.
- `data/CCPP/Folds5x2_pp.xlsx` contains the Combined Cycle Power Plant dataset.
- `requirements.txt` contains the required Python libraries.

## Running the Notebook

Install the required libraries using:

pip install -r requirements.txt

Then open the notebook from the `notebook` directory and run all cells.
